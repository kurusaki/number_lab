## サンプルコードと資料について

各フォルダには、動画で使用したサンプルコードと、動画の内容を教科書形式でまとめた資料（README.md）を収録しています。

動画だけでは見返しにくい内容も、文章とコードで復習できるようになっています。
ぜひ動画とあわせてご活用ください。

また、このシリーズでは **common** フォルダに共通ライブラリを配置しています。

動画が進むにつれてライブラリにも機能を追加しながら、
実際の開発に近い形で学習を進めていきます。

---

## このシリーズで学べること

- コンピュータはなぜ2進数を使うのか
- 10進数・2進数・8進数・16進数
- ビットとバイト
- ビット演算
- シフト演算
- 論理演算
- 二の補数
- 浮動小数点数
- ASCII・Unicodeなどの文字コード

数の仕組みを理解することで、
ビット演算や文字コード、メモリ表現など、
プログラミングの基礎をより深く理解できるようになります。
