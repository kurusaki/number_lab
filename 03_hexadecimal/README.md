# 第1章 数の世界

#3 なぜ16進数なの？

---

## はじめに

前回は、10進数・2進数・8進数・16進数の違いと、それぞれの変換方法を学びました。

今回は、プログラミングで16進数がよく使われる理由を考えます。

コンピュータの内部では、値は0と1の組み合わせで扱われています。それなら、プログラマーもすべて2進数で読み書きすればよいのでしょうか。

2進数はコンピュータの動作を理解するうえで重要ですが、桁数が多くなるため、人間には読みづらいという問題があります。16進数を使うと、2進数の並びを短く、しかも規則的に表現できます。

---

## この章で学ぶこと

- 1桁の16進数と4ビットの関係
- 2桁の16進数で1バイトを表せる理由
- メモリアドレスが16進数で表示される理由
- カラーコードと16進数の関係
- ダンプ表示で16進数が使われる理由
- C言語で16進数を表示する方法

## 1桁の16進数は4ビット

16進数の1桁では、`0`から`F`までの16通りを表せます。

一方、2進数の4桁、つまり4ビットでも、`0000`から`1111`までの16通りを表せます。

```text
16進数  2進数
   0     0000
   1     0001
   2     0010
   3     0011
   4     0100
   5     0101
   6     0110
   7     0111
   8     1000
   9     1001
   A     1010
   B     1011
   C     1100
   D     1101
   E     1110
   F     1111
```

このように、16進数の1桁と2進数の4ビットは、ちょうど一対一で対応します。

例えば、2進数の`10101100`は、4ビットずつに区切ると簡単に16進数へ変換できます。

```text
2進数    1010 1100
           A    C
16進数      AC
```

反対方向の変換も同じです。16進数の`AC`を1桁ずつ2進数へ置き換えると、`10101100`になります。

---

## 2桁の16進数で1バイト

1バイトは8ビットです。16進数の1桁は4ビットに対応するため、16進数の2桁で1バイトを表せます。

```text
2進数    1111 1111
16進数      F    F
```

8ビットで表せる値は、`00000000`から`11111111`までです。16進数では、これを`00`から`FF`までの2桁で表せます。

```text
2進数    11111111
16進数         FF
10進数        255
```

`11111111`よりも`FF`のほうが短く、4ビットごとの境界も分かりやすくなります。これが、プログラマーにとって16進数が読みやすい大きな理由です。

---

## メモリアドレス

メモリアドレスは、メモリ上の場所を示す番号です。アドレスは大きな値になるため、10進数や2進数よりも、短く表現できる16進数がよく使われます。

C言語では、`printf()`の`%p`を使ってポインタの値を表示できます。

```c
printf("valueのアドレス : %p\n", (void *)&value);
```

実際に表示されるアドレスは実行環境や実行のたびに変わることがあります。また、`%p`による具体的な表示形式はC言語の処理系に依存しますが、多くの環境では16進数に似た形式で表示されます。

---

## カラーコード

Webページなどで使うRGBカラーコードも、16進数の身近な例です。

```text
#3399FF
```

これは2桁ずつ、赤・緑・青の強さを表しています。

```text
赤    33
緑    99
青    FF
```

各色は1バイトなので、`00`から`FF`までの256段階で表現できます。赤・緑・青をそれぞれ2桁で表し、合わせて6桁の16進数にしたものがRGBカラーコードです。

---

## ダンプ表示

メモリやファイルの内容を、実際に保存されているバイト単位で表示したものをダンプと呼びます。

例えば、文字列`Hello`を構成する5バイトは、16進数で次のように表示できます。

```text
48 65 6C 6C 6F
```

1バイトが常に16進数2桁になるため、値の区切りが揃って見やすくなります。デバッガ、通信データ、ファイル形式の調査などでダンプ表示が使われます。

---

## ソースコード

ファイル名：`03_hexadecimal/main.c`

```c
#include <stdint.h>
#include <stdio.h>
#include "../common/binary.h"

int main(void)
{
    uint8_t value = 0xAC;
    uint8_t data[] = {0x48, 0x65, 0x6C, 0x6C, 0x6F};
    unsigned int red = 0x33;
    unsigned int green = 0x99;
    unsigned int blue = 0xFF;

    printf("1桁の16進数は4ビットに対応\n");
    printf("0xA = 1010\n");
    printf("0xC = 1100\n");
    printf("0xAC = ");
    print_binary8(value);

    printf("\n2桁の16進数で1バイトを表現\n");
    printf("10進数 : %u\n", (unsigned int)value);
    printf("16進数 : 0x%02X\n", (unsigned int)value);
    printf("1バイトの最大値 : 0xFF = %u\n", UINT8_MAX);

    printf("\nメモリアドレス\n");
    printf("valueのアドレス : %p\n", (void *)&value);

    printf("\nカラーコード\n");
    printf("RGB(%u, %u, %u) = #%02X%02X%02X\n",
           red, green, blue, red, green, blue);

    printf("\nダンプ表示\n");
    for (size_t i = 0; i < sizeof(data); i++) {
        printf("%02X ", (unsigned int)data[i]);
    }
    putchar('\n');

    return 0;
}
```

---

## コードの解説

### 2進数と16進数を並べて確認する

`0xAC`を`uint8_t`型の変数へ代入しています。`uint8_t`は、符号を持たない8ビットの整数型です。

```c
uint8_t value = 0xAC;
```

`print_binary8()`を使うと、この値を8ビットの2進数で確認できます。

```text
0xAC = 10101100
```

### 16進数を2桁で表示する

`printf()`では、`%X`を使うと値を16進数の大文字で表示できます。

```c
printf("16進数 : 0x%02X\n", (unsigned int)value);
```

`02`は、最低2桁で表示し、桁が足りない場合は左側を`0`で埋める指定です。バイト単位の表示では、`%02X`がよく使われます。

### メモリアドレスを表示する

```c
printf("valueのアドレス : %p\n", (void *)&value);
```

`&value`で変数`value`のアドレスを取得し、`%p`で表示しています。`%p`へ渡すポインタは`void *`型へ変換しています。

### バイト列をダンプ表示する

```c
for (size_t i = 0; i < sizeof(data); i++) {
    printf("%02X ", (unsigned int)data[i]);
}
```

配列の各要素を先頭から順に取り出し、16進数2桁で表示しています。配列`data`の要素は1バイトなので、1要素が16進数2桁に対応します。

## まとめ

- 16進数の1桁は、2進数の4ビットに対応する
- 16進数の2桁は、8ビット、つまり1バイトに対応する
- 2進数を16進数にすると、短く、4ビット単位で読みやすくなる
- メモリアドレスは、大きな値を短く表すために16進数で表示されることが多い
- RGBカラーコードでは、赤・緑・青をそれぞれ16進数2桁で表す
- ダンプ表示では、1バイトを16進数2桁で揃えて表示できる
- C言語の`%X`は16進数、`%02X`は0埋めした2桁の16進数、`%p`はポインタの表示に使う
- 16進数は、コンピュータが扱う2進数と、人間の読みやすさをつなぐ表現である
