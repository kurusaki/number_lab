# 私たちは10進数を使っている

普段私たちが使っている数字は、

0から9までの10種類です。

これを

**10進数**

と呼びます。

例えば、

25という数字は、

```
2 × 10 + 5
```

という意味になっています。

私たちは普段、

この10進数を意識せずに使っています。

---

# コンピュータは10進数を理解している？

では、

コンピュータも10進数を理解しているのでしょうか。

実は違います。

コンピュータの中には、

何十億個ものトランジスタがあります。

トランジスタは、

電気が流れるか、

流れないか、

という2つの状態しか持っていません。

つまり、

```
ON

OFF
```

だけです。

これを数字で表すと、

```
ON → 1

OFF → 0
```

になります。

つまり、

コンピュータの内部では、

数字も文字も、

すべて0と1の組み合わせで表現されています。

---

# だから2進数を学ぶ

私たちは、

0から9までの数字を使って数を表しています。

一方、

コンピュータの内部では、

0と1の組み合わせを使って数を表現しています。

このように、

0と1だけを使って数を表す方法を、

**2進数**

と呼びます。

コンピュータの内部で、

数がどのように表現されているのかを理解するために、

プログラマーは2進数を学ぶのです。

---

# ビットとは？

0または1、

この1つ分の情報を

**1ビット**

と呼びます。

例えば、

```
0
```

これで1ビット。

```
1
```

これも1ビットです。

2ビットになると、

```
00
01
10
11
```

の4通りになります。

ビットが1つ増えるごとに、

表現できる情報は2倍になります。

---

# 8ビットで1バイト

8ビットになると、

```
00000000
```

から

```
11111111
```

まで、

全部で256通りの情報を表現できます。

この8ビットを、

**1バイト**

と呼びます。

プログラミングでは、

ビットやバイトという言葉が頻繁に登場します。

まずは、

「8ビットで1バイト」

ということを覚えておきましょう。

---

# ソースコードを見てみよう

それでは、

今回のソースコードを見てみます。

```c
#include <stdio.h>
#include "../common/binary.h"

int main(void)
{
    unsigned char number = 65;
    char ch = 'A';

    printf("10進数 : %u\n", number);
    printf("2進数  : ");
    print_binary8(number);

    printf("\n");

    printf("文字 : %c\n", ch);
    printf("文字コード : %d\n", ch);
    printf("2進数  : ");
    print_binary8(ch);

    return 0;
}
```

まず、

```c
unsigned char number = 65;
```

で、

10進数の65を用意しています。

続いて、

```c
char ch = 'A';
```

で、

文字の **'A'** を用意しています。

そのあと、

`printf()`で

数字や文字を表示し、

`print_binary8()`を使って、

それぞれを2進数でも表示しています。

ここで一つ考えてみてください。

数字の65と、

文字の'A'では、

まったく違うデータのように見えます。

では、

2進数で表示すると、

同じ結果になると思いますか？

それとも、

違う結果になると思いますか？

では、

実際に動かして確認してみましょう。

---

# コンパイル

ターミナルで、

```bash
clang main.c ../common/binary.c -o binary
```

を実行します。

今回は、

main.cと、

共通ライブラリのbinary.cを一緒にコンパイルしています。

---

# 実行

続いて、

```bash
./binary
```

を実行します。

すると、

次のように表示されます。

```text
10進数 : 65
2進数  : 01000001

文字 : A
文字コード : 65
2進数  : 01000001
```

---

# 実行結果を見てみよう

結果を見ると、

10進数の65も、

文字の'A'も、

どちらも

```
01000001
```

という同じビット列になっています。

画面では、

数字として表示されたり、

文字として表示されたりしていますが、

コンピュータの内部では、

どちらも同じ0と1の並びとして保存されています。

つまり、

コンピュータが扱っているのは、

文字でも数字でもなく、

**0と1の並び**なのです。
