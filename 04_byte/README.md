## はじめに

一般的なコンピュータでは、1バイトは8ビットです。

8ビットで表せる組み合わせは256通りですが、符号なし整数として扱ったときの最大値は256ではなく255です。

この回では、0と1の組み合わせから256通りが生まれる理由と、値の範囲が0から255になる理由を確認します。さらに、RGBカラーやASCII文字コードとの関係を、C言語のプログラムを動かしながら学びます。

- RGBの各成分と1バイトの関係
- ASCIIと1バイトの関係

## 1バイトは8ビット

ビットは、0または1の2つの状態を表します。

一般的なコンピュータでは、8個のビットをまとめた単位が1バイトです。

```text
1バイト = 8ビット
```

8ビットの最小のビットパターンは、すべてが0の状態です。

```text
00000000
```

最大のビットパターンは、すべてが1の状態です。

```text
11111111
```

---

## なぜ256通りになるのか

1ビットには、0と1の2通りがあります。

8個のビットがそれぞれ2通りの状態を持つため、組み合わせの数は次のようになります。

```text
2 × 2 × 2 × 2 × 2 × 2 × 2 × 2
= 2⁸
= 256通り
```

---

## なぜ最大値は255なのか

256通りの中には、値0も含まれています。

```text
00000000₂ = 0₁₀
11111111₂ = 255₁₀
```

0から255までの整数を数えると、全部で256個です。

連続する整数の個数は、次の式で求められます。

```text
最後の値 - 最初の値 + 1
```

最後に1を足すのは、最初の値と最後の値の両方を個数に含めるためです。

例えば、0から3までの整数は、`0`、`1`、`2`、`3`の4個です。

```text
3 - 0 + 1 = 4
```

3から0を引くだけでは3になりますが、最初の値である0も1個として数えるため、最後に1を足します。

同じように、0から255までの整数の個数は、次のように求められます。

```text
255 - 0 + 1 = 256
```

0と255の両方を含めて数えるため、最大値は255でも、値の個数は256個になります。

したがって、8ビットの符号なし整数では、次のようになります。

```text
組み合わせの数：256通り
値の範囲：0から255
```

組み合わせの数と最大値は同じではありません。0から数え始めるため、256通りの最大値が255になります。

---

## 16進数では00からFF

2進数の4ビットは、16進数の1桁に対応します。そのため、8ビットは16進数2桁で表せます。

```text
2進数    00000000 から 11111111
10進数          0 から       255
16進数         00 から        FF
```

次の3つは、すべて同じ値です。

```text
11111111₂ = 255₁₀ = FF₁₆
```

---

## RGBとの関係

一般的な24ビットカラーでは、赤・緑・青の各成分に8ビット、つまり1バイトを使います。

```text
R：0から255
G：0から255
B：0から255
```

赤を最大、緑と青を0にすると、次のようになります。

```text
RGB(255, 0, 0) = #FF0000
```

各成分に256通りあるため、RGB全体では次の組み合わせを表現できます。

```text
256 × 256 × 256 = 16,777,216通り
```

---

## ASCIIとの関係

標準のASCIIは7ビットの文字コードで、0から127までの128個のコードを使用します。

例えば、大文字の`A`には10進数の65が割り当てられています。

```text
文字      A
2進数    01000001
10進数   65
16進数   41
```

ASCIIの値は、1バイトの範囲である0から255にすべて収まります。そのため、ASCII文字は通常、1文字を1バイトで格納できます。

なお、「拡張ASCII」と呼ばれることがある128から255までの割り当ては、文字コードによって異なります。

## ソースコード

ファイル名：`04_byte/main.c`

```c
#include <stdint.h>
#include <stdio.h>
#include "../common/binary.h"

int main(void)
{
    uint8_t minimum = 0;
    uint8_t maximum = UINT8_MAX;
    unsigned int number_of_patterns = (unsigned int)UINT8_MAX + 1;

    uint8_t red = UINT8_MAX;
    uint8_t green = 0;
    uint8_t blue = 0;

    uint8_t ascii_code = 65;

    printf("1バイトは8ビット\n");
    printf("最小のビットパターン : ");
    print_binary8(minimum);
    printf("最大のビットパターン : ");
    print_binary8(maximum);

    printf("\n8ビットで表せる組み合わせ\n");
    printf("2の8乗 = %u通り\n", number_of_patterns);
    printf("符号なし整数の範囲 = %uから%u\n",
           (unsigned int)minimum,
           (unsigned int)maximum);
    printf("最大値を16進数で表示 = 0x%02X\n",
           (unsigned int)maximum);

    printf("\nRGBとの関係\n");
    printf("RGB(%u, %u, %u) = #%02X%02X%02X\n",
           (unsigned int)red,
           (unsigned int)green,
           (unsigned int)blue,
           (unsigned int)red,
           (unsigned int)green,
           (unsigned int)blue);

    printf("\nASCIIとの関係\n");
    printf("文字Aのコード = %u = 0x%02X = ",
           (unsigned int)ascii_code,
           (unsigned int)ascii_code);
    print_binary8(ascii_code);

    return 0;
}
```

---

## コードの解説

### 最小値と最大値

`uint8_t`は、符号を持たない8ビット整数型です。

```c
uint8_t minimum = 0;
uint8_t maximum = UINT8_MAX;
```

`UINT8_MAX`は、`uint8_t`で表せる最大値です。値は255です。

### 組み合わせの数

最大値に1を加えると、0を含む組み合わせの数を求められます。

```c
unsigned int number_of_patterns = (unsigned int)UINT8_MAX + 1;
```

計算前に`unsigned int`へ変換しているため、`uint8_t`の範囲を超える256も保持できます。

### 2進数を表示する

共通ライブラリの`print_binary8()`を使い、値を8桁の2進数で表示します。

```c
print_binary8(minimum);
print_binary8(maximum);
```

### RGBを表示する

赤を255、緑と青を0にして、同じ値を10進数と16進数のカラーコードで表示します。

```c
printf("RGB(%u, %u, %u) = #%02X%02X%02X\n",
       (unsigned int)red,
       (unsigned int)green,
       (unsigned int)blue,
       (unsigned int)red,
       (unsigned int)green,
       (unsigned int)blue);
```

### ASCIIコードを表示する

ASCIIの`A`に割り当てられた65を、10進数・16進数・2進数で表示します。

```c
uint8_t ascii_code = 65;
```

## C言語における「1バイト」の注意点

C言語の規格では、1バイトを構成するビット数は`CHAR_BIT`で示され、必ず8ビットとは限りません。

ただし、現在の一般的なパソコンや多くの環境では、1バイトは8ビットです。また、`uint8_t`は、処理系が正確に8ビットの符号なし整数型を提供できる場合に定義されます。

この教材では、現在一般的な8ビットバイトの環境を前提に説明しています。

## まとめ

- 一般的なコンピュータでは、1バイトは8ビット
- 8ビットの組み合わせは、2の8乗で256通り
- 0から数えるため、符号なし8ビット整数の最大値は255
- 8ビットの値は、16進数では`00`から`FF`
- 一般的なRGBでは、赤・緑・青にそれぞれ1バイトを使う
- 標準のASCIIは7ビットで、その値は1バイトに収まる
- C言語では、`uint8_t`で8ビットの符号なし整数を扱える

```text
1バイト
= 8ビット
= 256通り
= 符号なし整数では0から255
= 16進数では00からFF
```
