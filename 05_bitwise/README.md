## はじめに

コンピュータの中では、数値や文字、画像など、さまざまな情報が0と1の組み合わせで表現されています。

ビット演算は、整数を構成する各ビットを1桁ずつ直接操作する演算です。

この回では、ビット演算の基本となるAND・OR・XOR・NOTを、同じ2つの8ビット値で比較します。さらに、C言語のビット演算子を使って、計算結果を2進数と10進数で確認します。

## ビット演算とは？

ビット演算では、同じ位置にあるビットを1桁ずつ計算します。

この回では、次の2つの8ビット値を使います。

```text
A = 11001100
B = 10101010
```

4つの演算結果は、次のようになります。

```text
A       11001100
B       10101010

AND     10001000
OR      11101110
XOR     01100110
NOT A   00110011
```

---

## AND演算

ANDは、2つのビットが両方とも1の場合だけ、結果が1になります。

```text
0 AND 0 → 0
0 AND 1 → 0
1 AND 0 → 0
1 AND 1 → 1
```

C言語では、アンパサンド1つの`&`を使います。

```c
a & b
```

今回の値を計算すると、次のようになります。

```text
  11001100
& 10101010
-----------
  10001000
```

AND演算は、必要なビットだけを取り出すときに使えます。

例えば、`00001111`とのANDを計算すると、下位4ビットだけが残ります。

```text
  11010110
& 00001111
-----------
  00000110
```

必要なビットを選ぶために使う値を「ビットマスク」と呼びます。

---

## OR演算

ORは、2つのビットのどちらか一方でも1なら、結果が1になります。

```text
0 OR 0 → 0
0 OR 1 → 1
1 OR 0 → 1
1 OR 1 → 1
```

C言語では、縦棒1つの`|`を使います。

```c
a | b
```

今回の値を計算すると、次のようになります。

```text
  11001100
| 10101010
-----------
  11101110
```

OR演算は、特定のビットを1にしたいときに使えます。

```text
  11000000
| 00001111
-----------
  11001111
```

---

## XOR演算

XORは「エックス・オア」と読みます。2つのビットが異なる場合に1になります。

```text
0 XOR 0 → 0
0 XOR 1 → 1
1 XOR 0 → 1
1 XOR 1 → 0
```

C言語では、キャレット記号の`^`を使います。

```c
a ^ b
```

今回の値を計算すると、次のようになります。

```text
  11001100
^ 10101010
-----------
  01100110
```

XOR演算は、特定のビットを反転させるときに使えます。

```text
元の値     11001100
マスク     00001111
XOR結果    11000011
```

同じ値同士でXORを計算すると、結果は0になります。

```text
  11001100
^ 11001100
-----------
  00000000
```

---

## NOT演算

NOTは、1つの値のすべてのビットを反転します。

```text
0 → 1
1 → 0
```

C言語では、チルダ記号の`~`を使います。

```c
~a
```

8ビットの値として見ると、今回の結果は次のようになります。

```text
元の値    11001100
NOT結果   00110011
```

### C言語の整数拡張に注意する

`uint8_t`の値に`~`を適用すると、演算前に通常は`int`型へ整数拡張されます。そのため、`~a`の計算自体は8ビットより広い型で行われます。

このサンプルでは、下位8ビットの結果を扱うため、`uint8_t`へ明示的に変換しています。

```c
uint8_t not_result = (uint8_t)~a;
```

---

## C言語のビット演算子

```text
AND   &   両方が1なら1
OR    |   どちらかが1なら1
XOR   ^   異なれば1
NOT   ~   0と1を反転
```

AND・OR・XORは2つの値を使う二項演算です。NOTは1つの値を使う単項演算です。

---

## ソースコード

ファイル名：`05_bitwise/main.c`

```c
#include <stdint.h>
#include <stdio.h>

static void print_binary8(uint8_t value)
{
    for (int bit = 7; bit >= 0; bit--) {
        printf("%u", (unsigned int)((value >> bit) & 1u));
    }
}

static void print_result(const char *name, uint8_t value)
{
    printf("%-5s : ", name);
    print_binary8(value);
    printf("  10進数: %u\n", (unsigned int)value);
}

int main(void)
{
    uint8_t a = 0b11001100;
    uint8_t b = 0b10101010;

    uint8_t and_result = (uint8_t)(a & b);
    uint8_t or_result = (uint8_t)(a | b);
    uint8_t xor_result = (uint8_t)(a ^ b);
    uint8_t not_result = (uint8_t)~a;

    print_result("A", a);
    print_result("B", b);

    printf("\n");
    print_result("AND", and_result);
    print_result("OR", or_result);
    print_result("XOR", xor_result);
    print_result("NOT A", not_result);

    return 0;
}
```

---

## コードの解説

### 2進数で値を用意する

```c
uint8_t a = 0b11001100;
uint8_t b = 0b10101010;
```

`uint8_t`は、符号を持たない8ビット整数型です。

`0b`または`0B`で始まる2進整数定数は、C23で標準化されています。

### 4種類のビット演算を行う

```c
uint8_t and_result = (uint8_t)(a & b);
uint8_t or_result = (uint8_t)(a | b);
uint8_t xor_result = (uint8_t)(a ^ b);
uint8_t not_result = (uint8_t)~a;
```

4種類の演算結果を、それぞれ`uint8_t`型の変数へ保存しています。

### 8ビットの2進数を表示する

`print_binary8()`では、ビットを右へ移動する`>>`とAND演算を組み合わせ、各ビットが0か1かを調べています。

```c
(value >> bit) & 1u
```

最上位のビット7からビット0まで順番に表示するため、常に8桁の2進数になります。

## ビット演算と論理演算の違い

C言語には、ビット演算子に似た記号の論理演算子があります。

```text
ビットAND    &
論理AND      &&

ビットOR     |
論理OR       ||

ビットNOT    ~
論理NOT      !
```

`&`、`|`、`~`は整数を構成する各ビットを計算します。

`&&`、`||`、`!`は、条件式が真か偽かを判定するために使います。

似た名前と記号ですが、目的と計算方法は異なります。

## ビット演算が使われる場面

- 複数のオン・オフをまとめるフラグ管理
- 必要なビットだけを取り出すビットマスク
- 色データの分解と合成
- 通信データやファイル形式の解析
- ハードウェアのレジスタ制御

ビット演算を理解すると、整数を単なる数値としてではなく、0と1の集まりとして扱えるようになります。

## まとめ

- ビット演算は、整数を構成する各ビットを直接操作する
- ANDは、両方のビットが1の場合だけ1になる
- ORは、どちらか一方でも1なら1になる
- XORは、2つのビットが異なる場合に1になる
- NOTは、すべてのビットを反転する
- C言語では`&`、`|`、`^`、`~`を使う
- ビット演算は、ビットマスクやフラグ管理などに利用される
